**mode** -- Режим работы APCS. Number (целое). [Ext](#mode)

**modes_config** -- Настройки текущего mode. Table
- Общие
	- **Y_max** -- При каком кол-ве топлива/заряда в процентах от максимального кол-ва gen будет иметь максимальную мощность? Number
	- **Y_min** -- При каком кол-ве топлива/заряда в процентах от максимального кол-ва gen будет иметь минимальную мощность? Number
	- **gen_start** -- При каком кол-ве топлива/заряда в процентах от максимального кол-ва gen будет запускаться? Number
	- **gen_stop** -- При каком кол-ве топлива/заряда в процентах от максимального кол-ва gen будет останавливаться? Number
- mode 1
	- **auto_search_FS** -- Искать ли автоматически FS? Bool
	- **manual_FS_address_table** - Таблица адресов FS. Table с string значениями без ключей. Игнорируется если auto_search_FS == true
- mode 2
	- **auto_search_ES** -- Искать ли автоматически ES? Bool
	- **manual_ES_address_table** -- Таблица адресов ES. Table с string значениями без ключей. Игнорируется если auto_search_ES == true

**auto_search_gens** -- Искать ли автоматически gens? Bool

**manual_gens_address_table** -- Таблица адресов gens. Table с string значениями без ключей<!--ИЛИ  с string ключами и table значениями, но это зарезервировано. Пользователям лучше это пока не знать, так как оно не готово-->. Игнорируется если auto_search_gens == true

**reboot_with_err** -- Перезагружаться ли при ошибке в main? Bool. Рекомендуется ставить true если вы не разработчик. Если значние == false, то при ошибке будет выпадать BSoD

**time_sleep** -- Время ожидания между циклами если ничего не произошло. Number

**output** -- Выводить ли инфомацию на экран? Bool

**su** -- super users. Table с string значениями без ключей. Напишите никнеймы администраторов APCS

**users_can_use** -- Могут ли пользователи делать что-то. Table. O там для того, что бы делать сброс gen на M режиме. Больше про действия: [keyboard](/doc/keyboard.md). Больше про [users](/doc/users.md)

**remote** -- Настройки remote модуля. Table
- **encrypting** -- использовать ли [AES шифрование](https://ru.wikipedia.org/wiki/AES_(%D1%81%D1%82%D0%B0%D0%BD%D0%B4%D0%B0%D1%80%D1%82_%D1%88%D0%B8%D1%84%D1%80%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D1%8F))? Bool
- **AES_Keys** -- Таблица адресов mashines и ключов их шифрования. Table с ключами адресами и значениями ключами шифрования в кодировке base64 (128 бит в стандартном OpenComp)
- **control_port** -- Порт, который будет открыт для управления APCS. Number, от 1 до 65535
- **controller_port** -- Порт, для обратной связи с контроллером APCS. Number, от 1 до 65535
- **authorized_mashines** -- Таблица адресов авторизованных, легитимных remote-mashines. Table с ключами-адресами без значений. Они подобно su могут делать всё, что угодно.
- **unauthorized_mashines_can** -- Таблица того, что могут делать неавторизованные mashines. Table
	- **get_data** -- Могут ли неавторизованные mashines собирать данные датчиков? Bool
	- **set_state** -- Могут ли неавторизованные mashines устанавливать n-ный режим работы? Table с ключами-состояниями и с значениями Bool типа могут ли. Подобно users_can_use
	- **reset_state** -- Могут ли неавторизованные mashines сбрасывать состояние APCS из n-ного состояния? Table с ключами-состояниями и с значениями Bool типа могут ли. Подобно users_can_use.O


## mode
Всего существует несколько режимов работы данной APCS.

### Первый режим (1)
Просто сжигает топливо если оно есть.

Мощность вычитывается по формуле, которая создаётся динамически перед стартом главного цикла с помощью данных из настроек:

`y = k * x - b`, где y -- мощность; x -- кол-во топлива в процентах от максимального; k = `100 / (Y_max - Y_min)`; b = `Y_min * k`. Y_max > Y_min

### Второй режим (2)
Мощность вычитывается по формуле, которая создаётся динамически перед стартом главного цикла с помощью данных из настроек:

`y = k * x - b`, где y -- мощность; x -- кол-во заряда в процентах от максимального; k = `100 / (Y_max - Y_min)`; b = `Y_min * k`. Y_max < Y_min
